# 🎨 Pakem Framework (`pakem-framework`)

> **Look like Laravel, Run at Rust Speed.**  
> Menenun mahakarya perangkat lunak modern dengan ketelitian canting dan kekuatan pakem berkecepatan Rust.

Crate ini adalah wrapper dan re-export resmi dari crate inti [`pakem`](https://crates.io/crates/pakem).

## 🚀 Penggunaan

Anda dapat memasang `pakem-framework` atau `pakem` secara bebas:

```toml
[dependencies]
pakem-framework = "1.0"
```

atau:

```toml
[dependencies]
pakem = "1.0"
```

## 📖 Dokumentasi Lengkap
Kunjungi portal dokumentasi resmi di [https://pakem.my.id](https://pakem.my.id) atau repositori GitHub di [https://github.com/pakem-rs/framework](https://github.com/pakem-rs/framework).
